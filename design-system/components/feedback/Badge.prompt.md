Generic status chip. Use `tone` to match meaning: `warning` for "Đang làm", `success` for "Đã giao"/"Xanh", `danger` for "Quá hạn"/"Đỏ", `info` for channel tags (Zalo, Fanpage, GrabFood), `primary` for VIP.

```jsx
<Badge tone="warning">Bếp đang làm</Badge>
<Badge tone="primary" icon="⭐">VIP</Badge>
```
