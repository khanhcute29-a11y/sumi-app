# Sumi Bakery — Ops Web App UI Kit

Responsive recreation of the enterprise operations web app described in the brand brief. Desktop shows the fixed left `Sidebar`; below ~860px it swaps to the 4-icon `BottomNav` + "Thêm" popup sheet, matching the CRITICAL RESPONSIVE LAYOUT RULE.

Screens: `OrdersScreen.jsx` (Omnichannel Inbox kanban + 4-step new-order modal with Draw & Annotate placeholder, Trust Score, Emergency Stop, VIP Override, Broker ID, Version Control), `KdsScreen.jsx` (Bếp hằng ngày vs Tiệc Teabreak stations), `WarehouseScreen.jsx` (big-touch Voice-to-Text / photo-capture + FIFO tags), `CashbookScreen.jsx` (THU/CHI/CÔNG NỢ/P&L tabs + Z-Report chốt ca modal).

Not built in this kit (shown as placeholders behind "Thêm"): Vận Chuyển (shipper offline-first flow), Báo Cáo, Khách Hàng, Thiết lập — flagged in root README as follow-up work.
